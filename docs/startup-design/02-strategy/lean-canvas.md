# Lean Canvas: Rain in My Head

Created: 2026-11-18
Last updated: 2026-11-18

**Phase:** 4 · **Confidence:** Medium (secondary research; no interviews)

| Block | Content |
|---|---|
| **Problem** | 1. Algorithmic playlists loop the same songs. 2. Long-term favorites get forgotten. 3. There's no trustworthy "why," and people fear AI songs or paid placement. |
| **Existing alternatives** | Spotify Prompted Playlist, Discover Weekly, and DJ; ListenBrainz Weekly Jams; stats.fm; hand-made playlists |
| **Customer segments** | Long-Time Listeners (10+ years of history, non-technical); Self-Hosters (technical, set it up for themselves and others). Early adopters: Last.fm users in r/lastfm and r/selfhosted. |
| **Unique value proposition** | **Playlists from your whole listening life, with the reason for every song, written straight to Spotify. Your data stays yours.** |
| **Solution** | 1. Time-machine to explore eras. 2. Rediscovery playlists ready to go. 3. Rules you can see and adjust. 4. A "why this song" reason on every track. Runs locally, with Claude-assisted setup. Future: import from other listening apps that have free APIs. |
| **Channels** | GitHub README, r/selfhosted, r/lastfm, awesome-selfhosted, and a portfolio case study; timed to Wrapped season |
| **Revenue streams** | None, by design: free, open source, self-hosted. |
| **Cost structure** | The founder's time. The user pays for Spotify Premium and their own hosting. Zero hosting cost for the founder. |
| **Key metrics** | Portfolio: case-study views and interview conversations. Product: setup completion rate, playlists written per user, and the share of "why" reasons rated as accurate. |
| **Unfair advantage** | Explanations drawn from the user's own decades of Last.fm history, plus user-owned SQLite data. Spotify's business model doesn't allow either. [Opinion] |
