# Go-to-Market: Rain in My Head

Created: 2026-11-18
Last updated: 2026-11-18

**Phase:** 4 · **Goal:** a strong portfolio case study plus about 10–50 self-hosting users. Not growth.

## Launch strategy
- **When:** Wrapped season (early December), when interest in listening history peaks. If the product isn't ready in time, launch then with the case study alone.
- **What:** a GitHub README with a 30-second GIF; a guided setup doc; the portfolio case study.

## First 10 users
1. Yourself, plus 2 or 3 friends with Last.fm accounts (you set it up for them, which tests the non-technical path).
2. An "Introducing" post on r/selfhosted (Koito reached about 1K stars this way).
3. A post on r/lastfm framed as "playlists from your scrobbles, with reasons."
4. A pull request to add it to awesome-selfhosted.

## Channels, ranked
| Rank | Channel | Why |
|---|---|---|
| 1 | r/selfhosted | Proven for similar tools |
| 2 | r/lastfm | Exactly the target users |
| 3 | Portfolio site and LinkedIn | The real goal |
| 4 | awesome-selfhosted | Long-tail discovery |
| 5 | Product Hunt or Show HN | Little evidence it works for this kind of tool; optional |

## Milestones
- M1: the "Why this song" prototype is tested with 5 people (validation experiment #1).
- M2: the guided setup is finished by one non-technical friend without help.
- M3: public launch post.
- M4: the case study is published.
